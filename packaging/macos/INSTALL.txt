untype - installation notes
===========================

1. Install
   Drag "untype" onto the "Applications" shortcut in this window.
   The app is signed with a Developer ID certificate and notarized by Apple,
   so macOS opens it without any Gatekeeper warning. Requires macOS 14 or later.

2. First launch
   Open untype from Applications (or Spotlight). The window shows an
   onboarding checklist for the items below.

3. Permissions (System Settings > Privacy & Security)
   - Microphone: grant when macOS asks on the first recording.
   - Accessibility: add untype. Needed for the push-to-talk hotkey and for
     inserting text into the focused input field.
   - Input Monitoring: add untype if the hotkey does not fire while another
     app is in front.
   After changing a permission, quit and relaunch untype.

4. Provider credentials
   The welcome screen's "Set keys..." button (also Settings > Credentials >
   "Edit keys...") stores your provider keys in ~/.tool-agents/untype/.env,
   readable only by you. Enter at least one speech-to-text key; the LLM keys
   are only needed if you enable refinement or translation.

   You can also edit that file directly: on the first session start untype
   creates it as a fully commented template listing every setting with its
   description and default. Remove the leading "# " on the lines you need:

     SONIOX_API_KEY=...          # default provider
     ELEVENLABS_API_KEY=...      # alternative provider

   Optional, only if you enable LLM refinement / translation:

     AZURE_OPENAI_API_KEY=...    # default LLM provider
     AZURE_OPENAI_ENDPOINT=https://<resource>.openai.azure.com
     AZURE_OPENAI_DEPLOYMENT=<deployment-name>
     AZURE_OPENAI_API_VERSION=<api-version>
     GOOGLE_API_KEY=...          # if you switch the LLM provider to google

   The prompt files the app uses are created in the same folder on first run.
   Settings left commented out are simply unset: missing required settings
   are reported as errors, nothing is silently defaulted.

5. Use
   Hold the configured push-to-talk hotkey, speak, release. The processed
   text is inserted into the focused input control and, if enabled, copied
   to the clipboard.

Homebrew alternative: brew tap BikS2013/untype && brew install --cask untype
(upgrades with brew upgrade --cask untype).

Upgrading: replace the app in Applications with the new version; existing
permissions and settings are kept as long as the app stays signed with the
same Developer ID.
